# Code of Conduct

This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
The rules apply in issues, pull requests, discussions and any other space the
project uses.

In short, treat people with respect. Assume good intent, and be patient with
people who are new to the project or to browser recording. Keep criticism
focused on the code and the decision, not on the person. Do not harass,
insult, threaten or discriminate against anyone. Do not publish someone else's
private information without their consent.

## Reporting a problem

Report unacceptable behavior to the maintainer, Mateus Silva
([@mateuscmtropical](https://github.com/mateuscmtropical)), through the
[private reporting form](https://github.com/mateuscmtropical/durable-recorder/security/advisories/new)
in the Security tab. Only the maintainer can read it. Start the title with
"Conduct:" and describe what happened, when, and where. Do not post the report
in a public issue or pull request.

The maintainer reviews each report and decides what to do. The full enforcement
guidelines are in the Contributor Covenant text linked above.
