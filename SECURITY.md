# Security policy

## Supported versions

Only the latest minor release receives security fixes.

## Reporting a vulnerability

Do not open a public issue or pull request for a security problem. Report it
privately instead:

1. Open the [Security tab](https://github.com/mateuscmtropical/durable-recorder/security)
   of the repository.
2. Choose **Report a vulnerability**.
3. Describe the problem.

Include as much of this as you can:

- What the problem is and what an attacker could do with it.
- The affected version.
- The browser, its version, the operating system and the device you tested on.
- Steps to reproduce it. A small page or code sample helps a lot.

## What to expect

These are goals, not promises:

- Acknowledge the report within a week.
- Keep you updated while the fix is prepared.
- Ship the fix in the latest minor release, and credit you in the release
  notes if you want that.
