durable-recorder demo

Record audio, video or the screen. Each slice goes to IndexedDB as it arrives, so a reload in the middle of a recording keeps what was captured. Browsers allow microphone, camera and screen access only on secure pages. localhost counts as secure.

Record

Screen recording is not supported in this browser.

The synthetic stream draws a canvas and plays an oscillator. It needs no permission.

Limits apply to the next recording. Leave them empty for no limit.

Stop keeps the recording. Cancel deletes it.
