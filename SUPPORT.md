# Support

## Questions

Ask questions in GitHub Discussions once the repository enables it. Until then,
open an issue with your question.

## Bugs

Open an issue with the [bug report form](https://github.com/mateuscmtropical/durable-recorder/issues/new/choose). Recording bugs
depend on the browser and the device, so include:

- The browser and its version.
- The operating system and the device. Give the phone model if you use one.
- The source you recorded: audio, video or screen.
- The library version.
- The recording options you used.
- The steps you took, what you expected and what happened.
- Logs from the browser console, if you have them.

## Security problems

Do not report security problems in an issue. Read the
[security policy](SECURITY.md) instead.
